# 🎬 YouTube 文字起こしアプリ

YouTube の URL を入れるだけで、**動画で話している内容を全文テキストに書き起こす**個人用 Web アプリです。
サーバー不要・インストール不要。ブラウザで開くだけで動きます。

## ✨ 主な機能

- **🔗 URL を貼るだけ** … `https://www.youtube.com/watch?v=...` や `https://youtu.be/...`、Shorts、動画ID にも対応
- **📝 全文文字起こし** … YouTube が持つ字幕（手動字幕・**自動生成字幕**の両方）を取得して全文表示
- **🌐 言語切り替え** … 複数の字幕がある動画は言語を選んで切り替え
- **⏱ タイムスタンプ** … 表示の ON/OFF を切替。クリックでその時間から YouTube を再生
- **📋 コピー / ⬇ ダウンロード** … 全文をワンタップでコピー、または `.txt` で保存
- **🕘 履歴** … 文字起こしした動画はこの端末に保存され、オフラインでも読み返せます
- **📱 PWA 対応** … スマホのホーム画面に追加してアプリのように使えます

## 🚀 使い方

ブラウザで `index.html` を開くだけ。

```bash
# 簡易サーバーで開く（推奨）
python3 -m http.server 8000   # → http://localhost:8000
```

GitHub Pages にそのまま公開しても動きます。

1. YouTube の URL を入力欄に貼る
2. 「文字起こし」を押す
3. 全文が表示される → コピー / 保存 / 言語切替

## ⚙ 仕組みと制約（字幕取得方式）

このアプリは**音声をAIで解析するのではなく、YouTube が用意している字幕データを取得**して文字起こしを行います。
そのため：

- ✅ 字幕（自動生成含む）がある動画は、ほぼすべて文字起こしできます
- ⚠️ **字幕が一切ない動画は文字起こしできません**
- ⚠️ ブラウザから YouTube へ直接アクセスできない（CORS 制約）ため、**中継用の CORS プロキシ**を経由します

### プロキシについて

既定でいくつかの公開 CORS プロキシを順番に試します。取得に失敗する場合は、
画面下部の「⚙ 詳細設定」から別のプロキシURLを設定できます。

```
例) https://api.allorigins.win/raw?url=
```

`{url}` を含めると、その位置に対象URLが挿入されます（含めない場合は末尾に付与）。

> 公開プロキシは混雑や停止で不安定なことがあります。安定運用したい場合は、
> 自分用の CORS プロキシ（Cloudflare Workers など）を立てて設定するのがおすすめです。

## 📁 構成

```
index.html             画面（UI）
src/style.css          スタイル
src/app.js             アプリ本体（URL解析・字幕取得・表示・履歴）
manifest.webmanifest   PWA 設定
sw.js                  オフライン用 Service Worker
icon.svg               アイコン
```

## 🔒 プライバシー

履歴・設定はすべて**この端末のブラウザ（localStorage）にのみ**保存されます。
外部に送信されるのは、字幕取得のために経由する CORS プロキシへのリクエストのみです。

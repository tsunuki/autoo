# 📘 ITパスポート 暗記アプリ

ITパスポート試験でよく出題される問題を、暗記カード形式と4択クイズで学習できるWebアプリです。
自分でオリジナル問題を追加・編集・削除でき、検索やMarkdown解説にも対応しています。

## ✨ 主な機能

- **📖 学習モード** … 問題→答えをめくる暗記カード形式。シャッフルやお気に入り登録に対応
- **📝 クイズモード** … 4択で即採点。正解・不正解と解説をその場で表示
- **🗂 問題管理** … 自分で問題を追加・編集・削除（ブラウザに保存される＝消えない）
- **🔍 検索 / 絞り込み** … キーワード検索、カテゴリ別、お気に入りのみ表示
- **📊 成績** … 正答率の記録、間違えた回数の多い「苦手問題」を表示
- **📝 Markdown対応** … 解説に `**太字**`・`# 見出し`・`- リスト`・`` `コード` `` が使えます

内蔵問題はストラテジ系・マネジメント系・テクノロジ系の3分野をカバーしています。

## 🚀 使い方

サーバー不要。ブラウザで `index.html` を開くだけで動きます。

```bash
# どちらでもOK
open index.html            # macOS
# もしくは簡易サーバーで
python3 -m http.server 8000   # → http://localhost:8000
```

データ（自作問題・成績・お気に入り）はブラウザの localStorage に保存されます。

## 📁 構成

```
index.html        画面（UI）
src/style.css     スタイル
src/questions.js  内蔵の頻出問題データ
src/markdown.js   軽量Markdownパーサー
src/app.js        アプリ本体ロジック
```

## 🛠 問題の追加方法

「🗂 問題管理」タブのフォームから、カテゴリ・問題文・選択肢・正解・解説を入力して保存するだけ。
解説欄はMarkdownで書けます。
